#### 4. Postman

Твой ответ: «не знаю»

⚠️ Пробел. Postman — стандартный инструмент для тестирования API.

Что это:

«Postman — это инструмент для отправки HTTP-запросов к API. Позволяет тестировать GET, POST, PUT, DELETE, проверять статус-коды, заголовки, тело ответа. В нём можно сохранять коллекции запросов и запускать их повторно.»

Для QA: Postman — обязательный инструмент, если работаешь с API. Его спрашивают на собеседовании.

#### 10. Cookies vs localStorage
 
Твой ответ: «не помню»

⚠️ Пробел. Ты это проходила в Дне 5.

Правильный ответ:
- «Cookies — небольшие данные, которые браузер отправляет на сервер с каждым запросом. Используются для авторизации. localStorage — хранилище в браузере, данные не отправляются на сервер, живут до очистки. В нашем полигоне токен JWT хранится в localStorage.»

### Запомни ключевые термины:
- Postman — инструмент для API-тестирования.
- curl — проверка API без Postman.
- SQL — SELECT, INSERT, UPDATE, DELETE.
- Cookies — отправляются на сервер, localStorage — нет.
