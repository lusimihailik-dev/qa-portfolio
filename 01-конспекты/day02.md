# День 2 — Linux в контейнере (под mila)

### Навигация
- pwd — показать текущую папку
- ls -la — все файлы подробно
- cd ~ / cd .. / cd - — переходы
- ~ = домашняя папка, . = текущая, .. = родительская

### Файлы
- touch — создать пустой файл
- echo "текст" > файл — перезаписать
- echo "текст" >> файл — дозаписать
- cp — копировать, mv — переместить/переименовать
- rm — удалить (без корзины!)

### Права
- chmod 755 — владелец rwx, остальные r-x
- chmod 600 — только владелец rw
- r=4, w=2, x=1
- Права важны для тестирования безопасности

### Процессы
- ps aux — все процессы
- jobs — фоновые задачи
- sleep 100 & — запуск в фоне
- kill %1 — убить задачу
- kill -9 PID — принудительно

### Пакеты
- sudo apt update — обновить список
- sudo apt install -y пакет — установить
- curl — HTTP-запросы (нужен для API)
- tree — дерево папок

### Почему не работаю под root
Root в контейнере — песочница, но привычка вредная.
На реальной работе — обычный юзер + sudo для конкретных команд.

### Группы и сессии в Linux
- usermod -aG группа юзер — добавляет юзера в группу
- Изменение применяется только к НОВЫМ сессиям входа
- Закрытие/открытие терминала НЕ перелогин
- groups mila — показывает группы юзера в системе
- groups (без аргумента) — группы ТЕКУЩЕЙ сессии
- newgrp группа — временно подхватить группу в текущем терминале
- Полный выход из графической сессии и вход — надёжное решение

### Соединение команд в терминале
- `;` — выполнить обе, даже если первая упала
- `&&` — вторая только если первая успешна (самый частый)
- `||` — вторая только если первая упала
- `|` — передать вывод первой во вторую (pipe)
- НЕЛЬЗЯ использовать `+` как «и» — это имя файла или арифметика
