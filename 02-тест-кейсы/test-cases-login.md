### TC-01. Успешный вход с валидными данными

**Предусловие:** открыта страница логина

2. Ввести пароль: Password123

**Тип:** позитивный
**Уровень:** системное

### TC-03a. Отправка письма для сброса пароля

**Предусловие:** 
- Открыта страница логина
- Настроен тестовый почтовый ящик (Mailtrap)

**Шаги:**
1. Нажать «Забыл пароль»
2. Ввести email: user@example.com
3. Нажать «Отправить»
4. Открыть тестовый почтовый ящик (Mailtrap)

**Ожидаемый результат:**
- Письмо пришло в течение 1 минуты
- Тема письма: «Сброс пароля на Example.com»
- Отправитель: no-reply@example.com
- В письме есть ссылка для сброса
- Ссылка ведёт на https://example.com/reset?token=...
- Ссылка действует 24 часа

**Тип:** позитивный
**Уровень:** интеграционное (сайт + почтовый сервер)

### TC-03b. Смена пароля по ссылке из письма

**Предусловие:**
- Выполнен TC-03a (письмо получено)
- Есть доступ к тестовому ящику

**Шаги:**
1. Открыть письмо в Mailtrap
2. Скопировать ссылку для сброса
3. Перейти по ссылке
4. Ввести новый пароль: NewPassword456
5. Повторить новый пароль
6. Нажать «Сменить пароль»
7. Вернуться на страницу логина
8. Войти с новым паролем: NewPassword456

**Ожидаемый результат:**
- Пароль успешно изменён
- Вход с новым паролем работает
- Вход со старым паролем не работает
- Ссылка для сброса больше не активна

**Тип:** позитивный
**Уровень:** системное
