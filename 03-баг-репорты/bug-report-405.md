# BUG-01. Ошибка 405 при отправке формы логина

## Описание
При отправке формы логина с валидными данными возвращается ошибка 405 Method Not Allowed.

## Окружение
- URL: http://10.191.30.68/login.html
- Браузер: (укажи свой)
- Дата: 24.10.2026

## Шаги воспроизведения
1. Открыть http://10.191.30.68/login.html
2. Ввести email: user@example.com
3. Ввести пароль: Password123
4. Нажать «Войти»

## Ожидаемый результат
Переход в личный кабинет или сообщение «Вход выполнен»

## Фактический результат
Ошибка 405 Method Not Allowed

## Причина
Форма использует method="post", nginx не обрабатывает POST для статических файлов.

## Severity
Major

## Priority
High

## Статус
Исправлен (форма переделана на GET + fetch)
