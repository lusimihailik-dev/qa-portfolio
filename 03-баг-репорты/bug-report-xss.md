# BUG-08. XSS (Cross-Site Scripting) в поле «Имя» при регистрации

## Описание
При регистрации пользователя в поле «Имя» можно ввести JavaScript-код
(`<script>alert(1)</script>`). Скрипт сохраняется в БД и выполняется
при отображении данных пользователя.

## Окружение
- URL: http://10.191.30.52/register.html
- API: Flask + PostgreSQL
- Браузер: Google Chrome

## Шаги воспроизведения
1. Открыть http://10.191.30.52/register.html
2. В поле «Имя» ввести: `<script>alert(1)</script>`
3. Заполнить остальные поля: email (xss@example.com), пароль (Password123)
4. Нажать «Зарегистрироваться»
5. (Опционально) Открыть страницу, где отображается имя пользователя.

## Ожидаемый результат
Скрипт не выполняется. Теги экранируются (отображаются как текст).

## Фактический результат
Скрипт выполняется (появляется всплывающее окно). Данные сохраняются в БД
без экранирования.

## Severity
High (хранимая XSS, может украсть cookie/токены)

## Priority
High

## Рекомендации
1. Экранировать HTML-спецсимволы (`<` → `&lt;`, `>` → `&gt;`) перед сохранением в БД или при выводе.
2. Использовать CSP (Content Security Policy).
3. Валидировать входные данные на сервере.
