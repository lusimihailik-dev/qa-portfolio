# BUG-03. Пароли пользователей передаются в открытом виде через API

## Описание
API `/api/users` возвращает пароли пользователей в открытом виде в ответе JSON.
Любой, кто имеет доступ к API, может получить пароли всех пользователей.

## Окружение
- URL: http://10.191.30.68/api/users
- API: Flask на порту 3000
- БД: PostgreSQL (qa_polygon)

## Шаги воспроизведения
1. Выполнить GET-запрос: curl http://10.191.30.68/api/users
2. В ответе JSON видим поле "password" с паролем в открытом виде

## Ожидаемый результат
- API не возвращает пароль
- Пароль хранится в БД в виде хеша (bcrypt/argon2)
- Для проверки логина используется сравнение хеша

## Фактический результат
- API возвращает пароль в открытом виде
- Пароль хранится в БД в открытом виде

## Severity
Critical

## Priority
High

## Риски
- При утечке БД все пароли скомпрометированы
- Пароли видны в логах, кэше, DevTools
- Нет авторизации для доступа к API

## Рекомендации
1. Хранить пароли в виде хеша (bcrypt)
2. Не отдавать пароль через API
3. Добавить авторизацию (JWT)
