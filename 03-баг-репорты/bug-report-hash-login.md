# BUG-05. После хеширования паролей логин перестал работать

## Описание
После исправления BUG-03 (хеширование паролей) вход с верными данными
возвращает пустой массив [].

## Окружение
- URL: http://10.191.30.68/api/users
- API: Flask на порту 3000
- БД: PostgreSQL

## Шаги воспроизведения
1. Выполнить GET http://10.191.30.68/api/users?email=user@example.com&password=Password123
2. Получить []

## Ожидаемый результат
JSON с пользователем (без пароля)

## Фактический результат
Пустой массив []

## Причина
Хеши в БД не соответствовали реальным паролям (некорректно сгенерированы).

## Решение
Пересоздать хеши через bcrypt.hashpw для каждого пароля и обновить в БД.

## Severity
Critical

## Priority
High

## Статус
Исправлен (хеши пересозданы)
