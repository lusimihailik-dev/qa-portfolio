# BUG-04. Email и пароль передаются в URL (GET), API отдаёт список пользователей без авторизации

## Описание
1. Логин выполняется через GET-запрос: /api/users?email=...&password=...
   Email и пароль попадают в URL, историю браузера, логи сервера.
2. API /api/users без параметров отдаёт список всех пользователей (id, email)
   без какой-либо авторизации.

## Окружение
- URL: http://10.191.30.68/api/users
- API: Flask на порту 3000

## Шаги воспроизведения
1. Выполнить GET http://10.191.30.68/api/users
   → видим список всех пользователей с email и id
2. Ввести логин в форме
   → в URL появляются email и password

## Ожидаемый результат
- Логин — через POST, данные в теле запроса
- /api/users требует авторизации
- Обычный пользователь не видит список всех пользователей

## Фактический результат
- Логин через GET, email и пароль в URL
- Список пользователей доступен без авторизации

## Severity
High (PII exposure, информация о пользователях)

## Priority
High

## Рекомендации
1. Переделать логин на POST
2. Добавить авторизацию (JWT/сессия) для /api/users
3. Маскировать email в ответах для чужих пользователей
