# BUG-09. Нет ссылки на страницу «Смена пароля» в навигации

## Описание
Страница `change_password.html` существует и работает, но в навигационном
меню сайта отсутствует ссылка на неё. Пользователь не может перейти
на страницу смены пароля через интерфейс.

## Окружение
- URL: http://10.191.30.52/profile.html
- Браузер: Google Chrome

## Шаги воспроизведения
1. Открыть http://10.191.30.52/profile.html
2. Посмотреть на навигационное меню (Главная, Личный кабинет, Войти, Регистрация)
3. Убедиться, что ссылки «Сменить пароль» нет.

## Ожидаемый результат
В навигации есть ссылка «Сменить пароль», ведущая на `change_password.html`.

## Фактический результат
Ссылки нет. Пользователь может попасть на страницу только вручную (по прямому URL).

## Severity
Minor (функционал есть, но недоступен через UI)

## Priority
Medium (пользователь не может воспользоваться функцией)

## Рекомендации
Добавить ссылку «Сменить пароль» в навигационное меню на всех страницах.
