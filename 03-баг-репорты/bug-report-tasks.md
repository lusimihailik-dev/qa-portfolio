# BUG-13. Задача не сохраняется без авторизации

## Описание
При попытке добавить задачу на странице `tasks.html` без авторизации
задача не сохраняется. API возвращает `401 Unauthorized`, но пользователь
не видит сообщения об ошибке.

## Окружение
- URL: http://10.191.30.52/tasks.html
- Браузер: Google Chrome

## Шаги воспроизведения
1. Открыть http://10.191.30.52/tasks.html без логина (токен отсутствует).
2. Ввести название задачи.
3. Нажать «Добавить».

## Ожидаемый результат
Пользователь перенаправляется на страницу логина (или видит сообщение
«Вы не авторизованы»).

## Фактический результат
Задача не сохраняется. Ошибка не отображается.

## Severity
Minor (пользователь не понимает, почему задача не создаётся)

## Priority
Medium

## Рекомендации
Добавить проверку токена в `tasks.html` (перенаправление на логин,
если токена нет).
