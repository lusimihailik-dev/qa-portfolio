# День 1 — LXD и первый контейнер

## 1. Что такое LXD и зачем он QA
LXD — это менеджер контейнеров (система контейнеризации) в Ubuntu. Он позволяет запускать изолированные мини-системы (контейнеры) внутри твоей основной ОС.

## Чем контейнер отличается от виртуальной машины (VM):

                Контейнер (LXD)         	Виртуальная машина
Ядро    	Использует ядро хоста   	Своё ядро
Размер   	~100–500 МБ             	~1–2 ГБ
Запуск   	Секунды                 	Минуты
Изоляция	На уровне ОС                    Полная (аппаратная)
Для QA  	Идеально для быстрых песочниц	Тяжело, медленно

## Зачем QA контейнер:

Песочница — можно ломать, ставить, удалять, не боясь сломать основную систему.
Тестовый стенд — можно поднять сайт, API, БД в отдельных контейнерах.
Изоляция — каждый сервис в своём контейнере, как в реальной работе.
Быстро — создать/удалить контейнер — секунды.

## 2. Установка и проверка LXD
bash
lxc --version          # проверить версию
lxc remote list        # список репозиториев образов
lxc image list ubuntu: # образы Ubuntu (контейнерные)

Важно: lxc — это клиент. Есть ещё lxd — демон (сервис). Команды управления — через lxc.

## 3. Создание и управление контейнером
bash
lxc launch ubuntu:22.04 qa-base    # создать и запустить контейнер qa-base
lxc list                            # список контейнеров и их статус
lxc info qa-base                    # подробная информация
lxc start qa-base                   # запустить остановленный
lxc stop qa-base                    # остановить
lxc delete qa-base                  # удалить

Разбор lxc launch:
ubuntu:22.04 — образ (репозиторий ubuntu, версия 22.04)
qa-base — имя контейнера

## 4. Работа внутри контейнера
bash
lxc exec qa-base bash              # зайти как root
lxc exec qa-base -- su - mila      # зайти как пользователь mila
lxc exec qa-base -- ls /home       # выполнить одну команду

Важно: внутри контейнера ты работаешь как в обычной Ubuntu. Все команды Linux (День 2) применимы.

Выход из контейнера:

bash
exit

## 5. Передача файлов между хостом и контейнером
bash
lxc file pull qa-base/home/mila/file.txt ~/file.txt   # из контейнера на хост
lxc file push ~/file.txt qa-base/home/mila/file.txt   # с хоста в контейнер

## 6. Группа lxd и права доступа
Проблема: после установки LXD обычный пользователь не может управлять контейнерами — permission denied.

Решение:

bash
sudo usermod -aG lxd mila    # добавить в группу
newgrp lxd                   # подхватить в текущем терминале
groups                       # проверить

Важно: изменение групп применяется только к новым сессиям входа. Закрытие/открытие терминала — не считается. Нужен полный Log Out / Log In или перезагрузка.

Проверка:

bash
id               # группы текущей сессии
id mila          # группы в системе (файл /etc/group)

Может быть расхождение: в системе группа есть, в текущей сессии — нет. Это классический баг/вопрос на собеседовании.
