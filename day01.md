# День 1 — LXD и первый контейнер

## Что такое LXD/LXC
LXD — менеджер контейнеров в Ubuntu. Позволяет запускать изолированные
мини-системы (контейнеры), которые используют ядро хоста. Лёгкие и быстрые,
в отличие от виртуальных машин.

## Команды дня
- lxc remote list — список репозиториев образов
- lxc image list ubuntu: — образы Ubuntu
- lxc launch ubuntu:22.04 qa-base — создать и запустить контейнер
- lxc list — статус контейнеров
- lxc exec qa-base bash — зайти внутрь
- exit — выйти из контейнера / из root
