# # День 16 — Postman

## API (Application Programming Interface — программный интерфейс приложения)
- это «мостик» или «переводчик», который позволяет одной программе общаться 
с другой.

## Postman
### Что такое Postman
- Инструмент для тестирования API
- Отправляет GET/POST/PUT/DELETE
- Сохраняет коллекции запросов

### Что сделано
- Установлен Postman (или использован curl)
- Создан запрос GET /users (с токеном) → 200 OK
- Создан запрос POST /login → 200 OK, получен токен
- Сохранена коллекция «QA Polygon API»
- Проверен негативный сценарий: GET /users без токена → 401

### Проверка
- POST /login → 200 OK, токен
- GET /users с токеном → 200 OK, список пользователей
- GET /users без токена → 401 Unauthorized
