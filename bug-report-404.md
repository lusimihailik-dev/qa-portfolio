# BUG-02. Ошибка 404 после успешного входа

## Описание
После успешного входа происходит редирект на welcome.html, но страница не существует.

## Окружение
- URL: http://10.191.30.68/login.html
- Браузер: (укажи свой)

## Шаги воспроизведения
1. Открыть http://10.191.30.68/login.html
2. Ввести верные данные: user@example.com / Password123
3. Нажать «Войти»
4. Дождаться сообщения «Вход выполнен!»

## Ожидаемый результат
Переход на страницу welcome.html с приветствием

## Фактический результат
404 Not Found — файл welcome.html отсутствует

## Причина
Скрипт перенаправляет на welcome.html, но файл не был создан.

## Severity
Major

## Priority
High

## Статус
Исправлен (создан welcome.html)
