# BUG-12. Неконсистентное расположение ссылки «Список задач» в навигации

## Описание
Ссылка «Список задач» на разных страницах сайта находится на разных позициях:
на одних страницах она шестая, на других — третья. Это создаёт путаницу
для пользователя.

## Окружение
- URL: http://10.191.30.52/tasks.html (и другие страницы)
- Браузер: Google Chrome

## Шаги воспроизведения
1. Открыть http://10.191.30.52/profile.html — ссылка «Список задач» шестая.
2. Открыть http://10.191.30.52/tasks.html — ссылка «Список задач» третья.
3. Сравнить порядок ссылок.

## Ожидаемый результат
На всех страницах навигационное меню одинаковое (одинаковый порядок ссылок).

## Фактический результат
Порядок ссылок различается.

## Severity
Minor (косметический, но влияет на UX)

## Priority
Medium

## Рекомендации
Привести навигационное меню к единому виду на всех страницах.
