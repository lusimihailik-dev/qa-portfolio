# День 14 — Тест-дизайн (полный разбор)

### Классы эквивалентности
- Разбить значения на группы с одинаковым поведением
- Один тест на класс
- Пример: возраст 18–65 → 3 класса (валидный, невалидный меньше <18,
 невалидный больше >65)

### Граничные значения
- Проверяем границы и ±1
- Пример: 17, 18, 19, 64, 65, 66

### Комбинация
- Классы + границы = 6–7 тестов вместо 48

### Попарное тестирование
- Сокращает комбинации параметров
- 3 параметра по 3 значения = 9 тестов вместо 27

### Таблица решений
- Для сложной логики (много «если»)
- Пример: скидка (VIP, сумма, скидка)

### Как протестировать форму логина
- Позитивные, негативные, границы, безопасность, интеграция, UI

### Чек-лист vs Тест-кейс
- Чек-лист — это список того, что нужно проверить
- Тест-кейс — это как проверить и что ожидать

### Исследовательское тестирование
- Без тест-кейсов, «играем» с приложением

### Как выбрать данные
- Классы → границы → негативные → комбинации

### Покрытие тестами
- Процент функционала, покрытого тестами
