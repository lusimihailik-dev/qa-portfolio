# BUG-10. XSS в поле «Новый пароль» при смене пароля

## Описание
При смене пароля в поле «Новый пароль» можно ввести JavaScript-код
(`<script>alert(1)</script>`). Скрипт сохраняется в БД без экранирования
и выполняется при отображении.

## Окружение
- URL: http://10.191.30.52/change_password.html
- API: Flask + PostgreSQL
- Браузер: Google Chrome

## Шаги воспроизведения
1. Войти как user@example.com / NewPassword456.
2. Открыть http://10.191.30.52/change_password.html.
3. В поле «Старый пароль» ввести: NewPassword456.
4. В поле «Новый пароль» ввести: <script>alert(1)</script>.
5. Повторить новый пароль: <script>alert(1)</script>.
6. Нажать «Сменить пароль».

## Ожидаемый результат
Скрипт не выполняется. Пароль отклоняется (или экранируется).

## Фактический результат
Скрипт выполняется (появляется сообщение «Пароль успешно изменен»).
Пароль сохраняется в БД без экранирования.

## Severity
High (хранимая XSS, может украсть cookie/токены)

## Priority
High

## Рекомендации
1. Экранировать HTML-спецсимволы (`<` → `&lt;`, `>` → `&gt;`).
2. Валидировать пароль на сервере (разрешённые символы).
3. Использовать CSP.
