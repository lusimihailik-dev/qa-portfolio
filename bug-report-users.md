# BUG-07. /users возвращает список всех пользователей любому авторизованному

## Описание
Любой пользователь с валидным JWT-токеном может получить список всех
зарегистрированных пользователей (email, id, name). Это нарушает приватность.

## Окружение
- URL: http://10.191.30.50:3000/users
- API: Flask + JWT
- БД: PostgreSQL

## Шаги воспроизведения
1. Получить токен для user@example.com:
   curl -X POST http://10.191.30.50:3000/login -H "Content-Type: application/json" -d '{"email":"user@example.com","password":"Password123"}'
2. Выполнить GET-запрос с токеном:
   curl http://10.191.30.50:3000/users -H "Authorization: Bearer <токен>"

## Ожидаемый результат
Обычный пользователь видит только свои данные (или 403 Forbidden)

## Фактический результат
Возвращается список ВСЕХ пользователей (user, admin, newuser, test2, test3)

## Severity
High (нарушение приватности, утечка PII)

## Priority
High

## Рекомендации
1. Ограничить /users только для админа (роль admin)
2. Добавить /users/me для получения своих данных
3. Проверять роль в токене или в БД
