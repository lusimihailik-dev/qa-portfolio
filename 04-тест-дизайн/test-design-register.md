# Тест-дизайн: форма регистрации

## Имя (2–50)
1. 1 символ → ошибка
2. 2 символа → успешная регистрация
3. 3 символа → успешная регистрация
4. 49 символов → успешная регистрация
5. 50 символов → успешная регистрация
6. 51 символ → ошибка

## Email
1. Валидный: user@example.com → успешная регистрация
2. Без @: userexample.com → ошибка
3. С пробелом: user @example.com → ошибка
4. Слишком длинный: 300 символов → ошибка

## Пароль (8–20)
1. 7 символов → ошибка
2. 8 символов → успешная регистрация
3. 20 символов → успешная регистрация
4. 21 символ → ошибка

## Повтор пароля
1. Совпадает → успешная регистрация
2. Не совпадает → ошибка

## Итог
16 тестов покрывают всю форму.
